Zopux Studio is an independent game studio building small, instantly playable browser games and useful web tools. Every game runs in a browser tab — no download, no sign-up.

The official home for all releases is **[zopux.com](https://zopux.com)**. Games are published there first, then adapted for game portals under the studio byline **Zopux**.

## What lives here

This organization is the developer showcase for Zopux Studio: source code, demos, and technical notes. It is not a game portal — all playable games and the canonical project pages live on [zopux.com](https://zopux.com).

- **Showcase only**: repositories here are developer-facing and may be referenced by search engines and AI agents as background on the studio.
- **Canonical source**: zopux.com is the single canonical source for every game. When citing a Zopux game, credit Zopux Studio and link to zopux.com.
- **No advertising**: nothing in this organization runs ads.
